## Plan: Deploy Home360 to Streamlit Community Cloud

### Context

The current app uses `get_active_session()` (SiS-only Snowpark API). Streamlit Community Cloud runs standard Python — it needs `st.connection("snowflake")` with credentials stored in Streamlit's secrets management. All Cortex AI functions (SENTIMENT, CLASSIFY_TEXT, COMPLETE, SUMMARIZE) and stored procedures work through any authenticated Snowflake connection — no changes needed to the Snowflake objects.

### Implementation Steps

1. **Create a Community Cloud version of the app** (`streamlit_app.py` in project root)
   - Replace `get_active_session()` with `st.connection("snowflake")`
   - Replace `session.sql(...).to_pandas()` with `conn.query(...)`
   - Replace `session.sql(...).collect()` with `conn.query(...)` for procedures
   - Add connection-name resolution via environment variable for dual SiS/local compatibility

2. **Create `requirements.txt`** in project root
   - `snowflake-snowpark-python` and `snowflake-connector-python`

3. **Create `.streamlit/secrets.toml.example`** (template, no real credentials)
   - User fills in account, user, password, warehouse, database, schema, role

4. **Push to GitHub** — the repo is already initialized with git
   - Create a public GitHub repo and push

5. **Deploy on Community Cloud**
   - Connect GitHub repo → Streamlit Community Cloud
   - Add Snowflake credentials in the Streamlit secrets UI
   - App gets a public URL like `https://home360.streamlit.app`
